# MarketGo

Aplicativo de marketplace para delivery de lojas locais.

## Visão geral

O MarketGo foi desenvolvido para simular uma experiência real de compra por delivery, com foco em:

- seleção de lojas
- catálogo de produtos
- carrinho de compras
- checkout com entrega
- histórico de pedidos
- integração com Supabase
